WebUI 里能干什么

模块自带一个网页界面，在 KernelSU 管理器里点本模块的「打开 WebUI」就能进

顶上显示模块版本和有没有连上，下面每张卡片管一件事，点按钮会在最底下的黑框里输出结果

　

环境：一眼看清装了什么

显示 Root 管理器、TEESimulator、MT 管理器装没装

　

Keybox 部署：拿 keybox、装 keybox，需要时再写进 KeyMint

打开 keybox 下载页：跳到 keybox 下载页，文件你自己在浏览器里下

检测并部署已下载的 keybox：自动在下载目录里找、校验、备份旧的、装进 TEESimulator

修复 key 状态（RKP default + widevine）：手动点，只走 RKP

无效伪造信息（RKP 失败则回退传统模式）：手动点，先走 RKP、失败再走一次传统模式

后面这两个是给需要写 KeyMint / Keymaster 的机器用的，点了才执行，失败不影响已经装好的 keybox

你机器的 ROM 没带 KmInstallKeybox 时它会直接说跳过，不用管

　

MT2 目录迁移：把 MT 管理器的 mt2 目录挪到你要的位置

建立新目录并改写 mt2_path：建 /sdcard/Download/MT管理器目录，把旧 mt2 里的东西合并搬过去，
删掉空的旧目录，再写进 MT 的设置

查看目标路径：看它改的是哪

改完记得强制停止 MT 管理器再重开，不然 MT 会把旧值覆盖回去

　

系统清理：两条常用的

清空 logd 尺寸属性：把 persist.logd.size 等属性置空，日志缓冲区回到系统默认

关闭 USB 调试：关掉 adb 与无线调试，并清掉 persist.service.adb.* 属性

　

电池：看健康度、改优化策略

查询电池寿命：读出设计容量、当前容量、循环次数、剩余百分比

全部不优化 / 全部优化：一键把全机应用加进或移出电池优化白名单（影响几百个包，要几十秒）

开机自动执行：让它每次开机自动跑上面两种策略之一，默认不自动

　

色彩饱和度：调屏幕颜色

填 0.1 到 3.0 点应用立刻生效，1.0 是系统默认

开机自动应用：填数值就是每次开机自动下发，留空就是关闭

　

隐藏设置：打开 GMS 里藏起来的设置入口

　

屏幕亮度：解掉亮度上限，或者一直保持最亮

查看当前亮度 / 查看支持的最大亮度 / 解锁最大亮度（上限自动读，不用填数字）

开启持续解锁：每秒把亮度锁在上限，同时关掉自动亮度

解除持续解锁：停掉后台进程，并把亮度降到 40%，不会停在刺眼的满亮度

开机自动开启：让它每次开机自己开

　

扫盘检测：看看系统能不能被绕过读到 Android/data

用零宽字符探一下，能读到就是系统有漏洞，读不到就是安全

　

输出：干过什么都记着

每点一次按钮，执行的命令和结果都写在「输出」那个黑框里，报错也写在那里

忙的时候按钮会临时锁住，等当前任务跑完再点
