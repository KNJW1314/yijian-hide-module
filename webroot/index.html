Keybox 部署

当前状态 检测中
网页有人机验证，脚本下不到，需你在浏览器里手动下载。
下载完成后不用改名，点上面的「检测并部署」，模块会自动找到、校验、备份旧文件并装好。
下面两个按钮需要时手动点：都会把已部署的 keybox 写进 KeyMint / Keymaster，需要 root。 「修复 key 状态」只走 RKP；「无效伪造信息」先走 RKP、失败再回退传统模式。
走的是原生命令：LD_LIBRARY_PATH=/vendor/lib64/hw KmInstallKeybox keybox.xml <设备号> true rkp。

MT2 目录迁移

当前 mt2_path 检测中
顺序：先建 /sdcard/Download/MT管理器 → 合并搬走旧 MT2 目录里的文件 → 删空的旧目录 → 写入 mt2_path。
改完请【强制停止 MT 管理器】再重开，否则 MT 会用旧值覆写回去。

系统清理

清空 logd：把 persist.logd.size 等四个属性置空，让日志缓冲区回到系统默认。
关调试：关掉 adb_enabled / usb_debugging_enabled / wireless_adb_enabled，并清掉 persist.service.adb.* 等属性。

电池优化策略

当前策略 检测中
开机自动执行
两个策略互斥，选一个。「全部不优化」会把全机所有包加入 deviceidle 白名单， 并对三方应用设 active + 放开后台限制；「全部优化」则全部移出。 操作前会自动快照白名单，可回滚。
影响范围较大（几百个包），执行需要几十秒。

色彩饱和度

当前值 检测中
设为
开机自动应用
1.0 = 系统默认，0.1 ~ 3.0 可调。0.5 偏灰，1.5 鲜艳，2.0 很艳。
即时生效，调完马上就能看到颜色变化，不用重启。

持续解锁最大亮度

当前状态 检测中
开机自动开启
开启后每秒把亮度锁在上限，同时关闭自动亮度，防止被系统改回去。
解除会停掉后台进程，并把亮度降到 40%（不会停在刺眼的满亮度）。
